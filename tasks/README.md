# Практика с запросами

Работайте в `queries/`: каждый файл содержит только контракт результата и начальную заготовку. Запросы можно писать любым способом, который сохраняет смысл полей и проходит проверку на изменённых данных.

1. `joins.sql`: сопоставьте число строк после соединения с числом самостоятельных позиций и доставок. Проверьте, почему одна позиция появляется несколько раз.
2. `amounts.sql`: получите стоимость каждого заказа из позиций. Проверьте заказ с одинаковой стоимостью двух разных позиций.
3. `payments.sql`: посчитайте только успешные платежи по уникальному `transaction_ref`. Проверьте заказы без оплаты и с частичной оплатой.
4. `reconcile.sql`: объедините независимые суммы и покажите неоплаченный остаток для каждого заказа.
5. `final_report.sql`: исследуйте `reports/broken.sql`, затем самостоятельно исправьте отчёт. Проверка должна проходить после изменения данных.

Для первых четырёх файлов запускайте `python -I scripts/check.py --task <имя>`, где имя — `joins`, `amounts`, `payments` или `reconcile`. Финал: `python -I scripts/check.py --final`. При ошибке команда показывает заказ, поле и расхождение. Исправьте SQL и повторите проверку.
